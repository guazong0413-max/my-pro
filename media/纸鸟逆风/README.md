# 纸鸟逆风

[播放 90 秒成片](./纸鸟逆风.mp4) · [看分镜](./分镜.jpg)

孩子在渡口投出一架红纸飞机。纸尖扎进河面，老摆渡人用抄网把它捞回来。湿纸摊开，里面画着一只燕子。她取出干船票，画了一大一小两只燕子，折好后投回岸边。渡船离岸时，孩子捏着这张回信，空出一只手向她挥手。

全片采用无对白叙事。渡口、船、小孩、摆渡人、手、两架飞机和燕子都在本目录用二维矢量绘制。外景采用同一个空间坐标，桌面另设一个俯拍机位。河面、柴油机、纸声和拨弦配乐由本片的声音脚本合成。

## 用 Remotion 打开

在解压后的本目录或仓库的本目录运行。

~~~sh
npm ci
npm run studio
~~~

选择 **PaperWings**。Studio 的时间线上有 16 个画面段和 4 条声音。右侧的 water、ferry、foley、music 控制河岸环境、船、动作和音乐的音量。改完后运行以下命令，成片会写到本目录。

~~~sh
npm run verify
npm run render
~~~

构图为 1920 × 1080，每秒 30 帧，2700 帧。工程锁定 Remotion 4.0.547。Windows 上会优先使用标准路径的 Chrome，亦可通过环境变量 REMOTION_BROWSER_EXECUTABLE 指向本机浏览器。渲染所需的字体轮廓、纸纹和四条立体声音轨都已随工程提供。

## 导演分镜

| 成片时间 | 动作、机位与声音 |
| --- | --- |
| 00–04 秒 | 先看女孩捏着红纸的手。纸翼轻颤，能听见纸面和河水。 |
| 04–10 秒 | 全景交代岸在左、船在右。女孩的重心越过承重脚，鞋底轻轻敲在木板上。片名落在河岸上方的天空。 |
| 10–15 秒 | 中景保留抛纸的准备动作，手向胸前收，再送向右上。 |
| 15–20.4 秒 | 追红纸的弧线，岸线随镜头移动。风托住纸尖，又把飞机翻下去。 |
| 20.4–25 秒 | 水面低机位。第一圈涟漪从纸尖展开，红纸吸水、压扁，留在船尾边。 |
| 25–29.4 秒 | 摆渡人朝左下看，俯身拿网。船壳的轻响把注意力带回船上。 |
| 29.4–37.6 秒 | 网口在红纸下方入水，双手抬杆。留一点时间看水从网眼滴回河里。 |
| 37.6–43.8 秒 | 俯拍木桌。双手打开湿红纸，露出一只墨色燕子。 |
| 43.8–49.2 秒 | 切回岸上等候的孩子，音乐和船机都放轻，保留一声远鸟。 |
| 49.2–58.8 秒 | 湿纸留在桌左，一张干船票压在右手边。铅笔分八笔画两只燕子，每一笔有各自的落笔、拖动和停顿。 |
| 58.8–65 秒 | 同侧俯拍。先折两个角，再合中线、拉开机翼。蓝条印在票边，折好后仍能辨认。 |
| 65–69.8 秒 | 摆渡人把干纸飞机举到船尾，向岸上轻投。 |
| 69.8–74 秒 | 镜头由右向左追回信，孩子先进入画面边缘。 |
| 74–78.4 秒 | 女孩接住纸飞机下方的折脊，收至胸前，第二只手才托上来。 |
| 78.4–83.4 秒 | 给孩子手中的纸翼一个特写，看到两只燕子。画外柴油机提速，传来送别的笛音。 |
| 83.4–90 秒 | 回到同一侧的全景。船往右驶离，孩子留在岸边挥手。两只燕子从水面上方掠过。 |

## 修改与复核

[时间线与动作](./src/motion.cjs)控制航迹、角色骨架和相机。[同步时刻](./src/cues.json)存放投掷、碰水、捞起、接住及八笔绘图的时间。[角色](./src/Actors.jsx)、[河岸和渡船](./src/Harbor.jsx)、[折纸和俯拍](./src/Paper.jsx)可以分别改画。[Remotion 合成](./src/Film.jsx)负责按帧剪切和载入分轨。

第一轮样片里，风衣遮住了孩子投掷时的眼睛，近景的机翼又遮住接纸后的嘴。调整了蓄力和回收的高度，拇指与机腹共用握点。桌面镜头的袖子原先停在画面里，已延伸出画，写字时的手指压在笔杆上。摆渡人的袖口收在上臂末端，水中镜头扩大了范围，让帽顶与抄网同框。湿纸吸水后颜色变暗，展平后才切到桌面。

[逐帧校验](./verify.cjs)检查踩实的脚在码头上的位置、前后臂长度、纸尖与水纹的接触点、红纸进入网口、抬网时纸与网的相对位置、捞纸镜头的上下边界，以及回信落入手后的连接。在 Studio 关闭四条声音可单看动作。试听时可依次静音河面与音乐，单听纸和铅笔。

## 声音与纸纹源文件

[声音脚本](./scripts/make_sound.py)使用固定随机种子生成 48 kHz 立体声。河水由缓慢的拍浪和零散水滴组成，船声含怠速、木壳和汽笛，动作层含脚步、入水、折纸和笔划。配乐由单独写出的音符序列生成。要重新生成分轨，安装 NumPy、SciPy 和 SoundFile 后运行以下命令。

~~~sh
python -B scripts/make_sound.py
~~~

片名使用 Noto Sans SC 的四个字形轮廓，纸面颗粒随镜头保持固定。[绘制脚本](./scripts/make_paper.py) · [字形授权](./public/OFL.txt)
