# 风里的邮差

一只系红围巾的鳄鱼骑车送信。32 秒里，它从晴朗的柠檬海港出发，穿过江南细雨和赤岩峡谷的风沙，最后在极光下把信投进驿站的红邮筒。

MP4 为 1920 × 1080、30 帧/秒，含立体声原声。下载单文件 HTML 后可以离线打开，拖动进度条或点击场景名跳转，点扬声器开启原声。

## 生成模型与制作方式

| 制作环节 | 模型或工具 | 在片中的工作 |
| --- | --- | --- |
| 创作与编程 | **GPT-6.2 Astra Max**（按创作者提供的 Codex 界面截图记录） | 设计四幕、编写原画提示词、骑行动作、天气效果、声音合成和导出脚本。 |
| 原画 | **Codex 内置图像生成工具（ImageGen）** | 分别绘制四张场景底画和一张透明背景的鳄鱼头像。此次工具回执未列出底层图像模型的具体版本。 |
| 动画与成片 | **JavaScript、Canvas 2D、Chrome、FFmpeg** | 车轮转角与曲柄共用骑行距离，两段式腿部动作让脚跟随踏板。换景时两侧画面使用同一时刻的姿势。Chrome 逐帧渲染 960 帧，FFmpeg 编码为 H.264 视频。 |
| 音乐与拟音 | **Python、NumPy、FFmpeg** | 合成三拍子旋律、车铃、链条、雨滴和风声，按时间轴混成立体声 AAC 音轨。 |

## 四幕

| 时间 | 场景与画风 | 动画细节 |
| --- | --- | --- |
| 00–08 秒 | 柠檬海港 · 复古水粉旅行海报 | 海鸥振翅，水面反光，海堤与路面以不同速度后移。 |

| 24–32 秒 | 极光驿站 · 分层剪纸 | 雪片穿过车灯，鳄鱼把信递入邮筒，镜头留在驿站。 |

## 原始成片

上方的 MP4 是完整的 32 秒播放版，保留 1080p、30 帧/秒与原音轨。为了便于直接下载，对视频做了第二次 H.264 编码。最初导出的 87,693,405 字节母版另以三个原始字节分卷保存在 [master 目录](./master/)。

下载项目后，从本目录执行以下命令，即可在本目录得到原始的 `风里的邮差.mp4`。脚本会校验 SHA-256。

```sh
python3 master/restore.py
```

母版 SHA-256 为 `83e209927be3dbb3b440b66df5502e564af6992a059c8336aa4b29d1ac9f22b2`。

## 源码与复现

从本目录打开 `index.html` 即可运行可编辑版。保留 `art/` 和同目录的四个 JavaScript 文件。`paint.js` 管理时间、镜头与色板，`rider.js` 绘制骑手和自行车，`scenery.js` 绘制环境与天气，`film.js` 串起场景和播放控件。

重新制作需要 Python 3、NumPy、Node.js、Chrome，以及支持 H.264 和 AAC 的 FFmpeg。渲染脚本默认使用 macOS 的 Google Chrome，其他安装位置可以通过 `CHROME_BIN` 指定浏览器可执行文件。依次运行：

```sh
python3 production/score.py
python3 production/pack.py
node production/render.cjs movie
```

三个命令分别生成 `art/ride.m4a`、可独立分享的 HTML 和带声音的 MP4。`node production/render.cjs controls` 可检查互动版的章节跳转、拖动、播放和声音。
