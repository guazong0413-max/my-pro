## 本版用到的动作和声音

- 复用四个角色的二维轮廓与校准表情。手用独立圆形，袖子随肩肘腕连成一块。小旭看向小美时稍抬下巴，回答后留半拍停顿。小宇的步幅和胯的位置由落脚点决定，台阶上脚底按每一级重新定位。[圆手与肩袖](../人物动作/rig.cjs) · [表情模型](../隔门一瓶水/characters/reference-style/)
- 用固定手腕和道具相对位置表达接触。门边收手先退离小旭的脸。面粉落点与门槛在同一个画面上，钥匙圆环挂在圆手外侧。[镜头与动作](./scenes.cjs) · [门、布景和角色绘制](./art.cjs)
- 重新生成了 16 条普通话干声。旁白用 Uncle_Fu，小美用 Serena，小旭用 Dylan。两句夜间对白加同房间的短反射。脚步压低，纸声、门扣、闹钟和钥匙各有各的入点。[剧本与入点](./story.json) · [混音源码](./mix.py) · [干声目录](./voice/)

## 验片和重导出

成片为 1920 × 1080、30 fps，共 2,700 帧和 18 个时间轴段落。逐帧检查脚位与抬脚状态、手脚目标是否可达和字幕区间。MP4 的图像与双声道音频均为 90.000 秒，已做完整解码。[逐帧检查](./verify.cjs)

在本目录运行。配音干声已归档，重导画面和混音可直接使用。环境需要 Node.js、Python 的 NumPy 与 SciPy，以及带 H.264 和 AAC 的 FFmpeg。使用 Windows 时默认读取微软雅黑，其他环境可通过 FILM_CJK_FONT 指向本地中文字体。

~~~sh
npm ci --prefix ../开篇九十秒
python mix.py
node verify.cjs
node film.cjs
~~~

如需改词重录，先准备千问的 qwen-tts 推理环境，再执行下列命令。配音生成脚本与开篇工程使用相同的 Qwen3-TTS-12Hz-1.7B-CustomVoice 模型。

~~~sh
python generate_voice.py --only mother soon
python mix.py
node film.cjs
~~~
