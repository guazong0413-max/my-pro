## 原文语气重配

反馈是上一版配音表演得太足，要求向千问交代原文的语气。上一版旁白将不少句子缩成了剧情大意，人物对白则用了整段通用的情绪提示。本版对照原片的对白、旁白和字幕，把原话拆成 28 段。人名以字幕字形为准，像「大叔看了一眼时间」这样的说法按原片实际读音录入。

| 成片位置 | 给千问的读法 |
| --- | --- |
| 00:08–00:11 | 小旭先问「妈妈呢？」，把「呢」短短地抬一下。留一拍再问「她怎么还不回来？」，一口气说完，「回来」收轻。 |
| 00:12–00:15 | 小美说「快了，马上就回来了」。「快了」短，稍停再接下半句，「马上」平着说，最后一个「了」轻收。 |
| 00:27–00:32 | 「到底是不是真的有救援？他为什么要告诉自己呢？」照心里顺口发问的节奏读，句子连着走，末尾短。 |
| 01:20–01:30 | 「突然响起」沿用叙述声量，闹铃另在走廊场景里响。门扣、脚步和钥匙各有入点，脚步保持轻。 |

每段的原话、最终发给千问的完整提示、音色和随机种子均可复核。用原片各句的时长和停顿选取样本，再用语音识别排查多读、漏读。短句里的多余长停顿在混音时缩短，部分旁白略调语速和音高以衔接相邻句子。小旭两问分别生成，保留中间的停顿。小美的气口随她这一条干声保留。对白的音量峰值做了轻度平滑，字幕和口型按新声轨生成。[配音稿和完整提示](./story.json) · [千问生成脚本](./generate_voice.py) · [干声目录](./voice/) · [混音源码](./mix.py)

## 人物动作

- 复用四个角色的二维轮廓与校准表情。手用独立圆形，袖子随肩肘腕连成一块。小旭看向小美时稍抬下巴，回答后留半拍停顿。小宇的步幅和胯的位置由落脚点决定，台阶上脚底按每一级重新定位。[圆手与肩袖](../人物动作/rig.cjs) · [表情模型](../隔门一瓶水/characters/reference-style/)
- 用固定手腕和道具相对位置表达接触。门边收手先退离小旭的脸。面粉落点与门槛在同一个画面上，钥匙圆环挂在圆手外侧。[镜头与动作](./scenes.cjs) · [门、布景和角色绘制](./art.cjs)
- 小美看猫眼时用背面造型，眼位落到同一扇门的猫眼上。小宇的开门和关门共用合页和把手，室内与走廊的机位分别投影台阶的位置。[本次朝向纠正](../制作纠错记录.md) · [系列场面调度规范](../AGENTS.md)

## 验片和重导出

成片为 1920 × 1080、30 fps，共 2,700 帧和 18 个时间轴段落。逐帧检查脚位、手脚可达范围和朝向。验片还核对了 45 条字幕的顺序与原词，以及两位角色的口型区间。正常导出会检查猫眼对齐、门轴、开合门的握点和门缝视野。MP4 的图像与双声道音频均为 90.000 秒，已做完整解码。[朝向检查](./blocking.cjs) · [逐帧验片](./verify.cjs)

在本目录运行。配音干声已归档，重导画面和混音可直接使用。环境需要 Node.js、Python 的 NumPy 与 SciPy，以及带 H.264、AAC 和 rubberband 滤镜的 FFmpeg。使用 Windows 时默认读取微软雅黑，其他环境可通过 FILM_CJK_FONT 指向本地中文字体。

~~~sh
npm ci --prefix ../开篇九十秒
python mix.py
node verify.cjs
node film.cjs
~~~

如需改词重录，先准备千问的 qwen-tts 推理环境，再执行下列命令。配音生成脚本与开篇工程使用相同的 Qwen3-TTS-12Hz-1.7B-CustomVoice 模型。

~~~sh
python generate_voice.py --only mother_first mother soon
python mix.py
node film.cjs
~~~
