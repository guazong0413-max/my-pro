## 人物与配音

- 小美沿用已有的赭色长外套、发髻和校准后的侧脸，小男孩沿用蓝色运动装的儿童模型。八楼女人另画了披发、酒红色连帽衣和疲惫的眉眼。两名成年女性在同一镜头尺度下也能靠轮廓区分。[人物模型](../隔门一瓶水/characters/) · [表情模型](../隔门一瓶水/characters/reference-style/)
- 中远景的手用一个圆形接住袖口。舀水和托瓷盖时，才画握柄方向、拇指压点和指腹承重。拉帘的水平位移拆成左右脚交替着地。看猫眼时，眼睛与镜筒中心在同一高度。
- 使用千问开源模型 `Qwen3-TTS-12Hz-1.7B-CustomVoice` 本地生成 21 条普通话干声。Uncle_Fu 用于旁白，白天以平声叙事，楼道出现动静后收低音量。Serena 用于八楼女人，保留“求你了”之后的停顿，再交代楼层。台词、音色、逐段指令和入点都在工程中。[配音脚本](./story.json) · [千问官方模型说明](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice)
- 瓷盖使用短促碰撞和逐渐消失的高频共振，门外敲击使用低频木门共振。鞋底与呼吸在立体声里由远而近再退去。门外女人的声音降低高频，并加入短走廊反射。全片保留敲门前后的停顿。[声音工程](./mix.py)

## 交付与复现

成片为 1920 × 1080、30 fps、2700 帧，图像和双声道 AAC 均为 90.000 秒。完成整片解码，复查了物资数量、开口字幕、窗帘脚步、贴眼位置和三次敲门的音频起点。原片开头综合响度为 −15.2 LUFS，本版为 −16.4 LUFS，真峰值 −1.7 dBTP。

在本目录运行以下命令。需要 Node.js、可显示中文的字体、Python 的 NumPy 与 SciPy，以及带 libx264 和 AAC 的 FFmpeg。Windows 默认读取微软雅黑，其他环境可通过 `FILM_CJK_FONT` 指向中文字体文件。请在仓库目录结构内运行，以读取相邻的角色模型。

```sh
npm ci
python mix.py --output mix.wav --performance performance.json
node film.cjs --audio mix.wav --out opening.mp4
```

如需改词重配，请先配置千问官方的 `qwen-tts` 推理环境，本次使用 0.1.1。以下示例只重录门外女人，再执行上面的混音与导出命令。已合成的全部干声保存在 `voice/`，直接重导成片时从混音开始即可。

```sh
python generate_voice.py --model Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice --only neighbor
```
