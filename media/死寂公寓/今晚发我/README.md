# 今晚发我

晚上八点四十七分，林岚被楼下的一声尖叫打断。等她看清有人跑进自己住的楼，手机先送来市民预警，随后送来周主管的两条消息。

## 模型、纠错与验片

- 保留短发、砖红开衫这两个识别点。远景行人分别用黄连帽衫、暗红外套和绿衣挎包区分。普通景别手掌取圆形，抬腕和摆臂用上下两段肢体求解。站立时单独校正髋高，走路时脚底位置按实际行进距离计算。
- 开场和俯视镜头保留同一组三号门牌、浅色排水管和雨棚。追逐在远路上，进楼在近路上。感应门先开启，绿衣人越过门槛后被门框遮住，随后门合拢。
- 私聊使用林岚的视角。点横幅时袖口延伸到画面外，反应镜头前补了拿起手机的动作。老板两次输入的内容都留在同一屏。
- 输出为 1920×1080、24 fps、H.264 和 48 kHz 双声道 AAC。完整解码 1,272 帧。复核进楼前、过门槛、消失、合门，以及点按、对方输入、来信的成片帧。将最终 MP4 音轨转成 16 kHz 单声道复核，普通话识别的两遍预警和三句内心话均与台词逐字相符。最终编码音轨实测 −18.58 LUFS、−3.12 dBTP。

## 声音来源与复现

警车和贴桌震动直接使用上一版[独立音效库](../独立音效库/README.md)的 A 版成品。运动声源、多普勒变化及马达碰桌的实现见 [synth.py](../独立音效库/synth.py)。雨混合库内制作版与 Erbsland-Music 的窗沿雨声实录，风使用 Anya_Media 的树冠实录，两项实录均为 CC0，原始录音和授权链接见音效库说明。尖叫单独用千问 Vivian 的受惊表演截取，保留实际使用的[街上尖叫干声](./voice/street.wav)。室外方向、墙面反射、玻璃低通、脚步、门锁和两次来信的音色都在本片的混音脚本中处理。

在本目录执行。需要 Python、NumPy、SciPy、SoundFile、FFmpeg、现代 Node.js 与本系列使用的 `@napi-rs/canvas`。Windows 下自动注册微软雅黑。可用 `APARTMENT_CANVAS` 指向已安装的 Canvas 包，用 `FFMPEG` 指向 FFmpeg 可执行文件。

```sh
python mix.py
node verify.cjs
node film.cjs
```
