# 《死寂公寓》表情校准

试片用四个独立的二维情境看表演。小宇隔门问话，小美犹豫后回应，小旭抬眼找小美，大叔听完消息后低住情绪。字幕给出情境，预览采用无声方式。

90 秒雨夜参考的 1:03.05–1:08.00 侧脸段同样以稳住头部轮廓和少数小线条交代表演。样片的画面用于取帧和观察。试片的布景与演出按现有四套原创人物画出来。

## 模型用法

face.cjs 提供四个角色各八种正侧面表情，使用实心眼点、短眉线、离散嘴形和小幅头颈动作。头部轮廓用原有二维路径，缩短了露在领口上方的颈段。眨眼压成短线，换嘴按发声片段保持。大叔的眼泪沿侧脸移动。

keyframes/ 中有 64 张可编辑的透明底 SVG。每张的眉、眼、嘴各有一个分组。timing.json 列出试片四个镜头的范围。

在含有 art.cjs、faces.cjs、models.cjs 的人物工程根目录运行命令。渲染需要 Node.js、已安装的 @napi-rs/canvas 和带 libx264 的 FFmpeg。

~~~sh
npm install
node reference-style/keyframes.cjs reference-style/keyframes
node reference-style/reel.cjs --ffmpeg ffmpeg --out reference-expression-preview.mp4
~~~
