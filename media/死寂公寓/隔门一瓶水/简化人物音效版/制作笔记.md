# 死寂公寓 · 隔门一瓶水

这版是 90 秒简化人物与音效试片。情节取自长素材 01:03:32–01:05:02，画面用项目的二维绘制工程重做。配音沿用项目已有的八条合成对白，重新做了音量、语速和空间处理。门链、瓶身、鞋底和对讲机的拟音由工程生成。

## 人物和表演

- 素材 01:03:39 附近，小宇的正脸以黑点眼睛、短眉和小圆嘴为主，脸型和发型在说话时保持稳定。50:13 附近的小美靠一边的短眉、嘴角和低头传达犹豫。小旭主要靠身高差和抬眼，大叔主要靠宽肩、胡须和停顿。常规镜头的手只需要一个小圆形。
- 上一版用较密的袖片边线、逐个画出的指节和同类侧脸结构来表现细节。衣褶和轮廓过多时，弯手会看出断开的形状，也削弱了人物之间的区别。
- 这版先画四套轮廓。小宇是灰帽衫和较窄的肩，小美是高发髻和较长的赭色外套，小旭以蓝衣白领和更低的身量区分，大叔使用宽肩、短须和耳麦。手臂在内部按肩、肘、腕定位，画面上使用一块闭合袖形。眉、眼、嘴独立，使用少量姿势与停顿。做法参考 [Toon Boom Harmony 剪纸角色绑定](https://docs.toonboom.com/help/harmony-25/essentials/getting-started/character-building.html) 和 [多姿势变形准备](https://docs.toonboom.com/help/harmony-22/premium/deformation/about-character-prep-multi-pose-deformation-rig.html)。
- 手部使用圆手和近景握手两种画法。近景只画能看清方向的四指、拇指和交叠，瓶前和瓶后分别合成。表情维持点眼、短眉以及小开口和短线嘴的切换。可参考 [Adobe Character Animator 的替换组](https://helpx.adobe.com/ph_fil/adobe-character-animator/desktop/creating-and-controlling-puppets/triggering-and-controlling-puppets.html)。

## 重导出

图像由 Node.js、Canvas 2D 和路径绘制生成。声音由 Python、NumPy、SciPy 和 FFmpeg 处理。镜头切点、对白和主要拟音事件都在 [时间轴](source/timeline.json) 中。从本目录打开终端，安装 Node.js、Python 和带 libx264 的 FFmpeg 后可运行下列命令。Windows 使用系统微软雅黑绘制片名和字幕，其他系统可给 film.cjs 传入中文字体。

```sh
cd source
npm ci
python -m pip install numpy scipy
python sound.py --out sound.wav
node film.cjs --width 1920 --out picture.mp4
node models.cjs characters.png
node verify.cjs
ffmpeg -i picture.mp4 -i sound.wav -c:v copy -c:a aac -b:a 192k -movflags +faststart final.mp4
```
