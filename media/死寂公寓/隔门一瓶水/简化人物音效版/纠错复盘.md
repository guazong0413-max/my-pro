# 《隔门一瓶水》纠错复盘

这份记录对应《死寂公寓》的 90 秒简化人物音效版。选段来自长素材 01:03:32–01:05:02。两份样片用于观察画风、表演、构图和声音，成片画面与拟音由工程制作。对照入口见 [90 秒成片](死寂公寓-隔门一瓶水-简化人物音效版.mp4) 和 [制作笔记](制作笔记.md)。

## 纠错步骤

1. **连续看参考，再记要保留的形状。** 对照长素材 01:03:39.66–01:03:41.97 的小宇正脸、00:50:13.64–00:50:15.00 的小美侧脸、00:48:27.50–00:48:31.66 的小旭双人镜头、01:04:43.90–01:04:46.69 的大叔。每段记下脸型、视线、手的大小、变化发生的时刻和保持时间。[素材观察记录](../characters/reference-style/README.md)
2. **先过造型，再做短动作。** 同比例比较四个人，先从剪影和大色块辨认角色，再看正脸和侧脸的静止状态。单测说话、眨眼、屈肘和圆手握物，确认这些状态读得清楚后再接回镜头。[角色对照图](死寂公寓-四角色简化稿.png) · [角色绘制源码](source/character.cjs)
3. **定接触时刻，再摆手、脚和道具。** 在时间轴上标好接触前、接触和离开三个阶段。递水先定瓶的位置，扶栏先定腕位，楼梯先定鞋底落在哪一级，门链先定两个挂点。常速回看动作，再逐帧检查这些点是否跟着正确的物体走。[镜头和动作源码](source/film.cjs) · [手和门链源码](source/props.cjs)
4. **用画面接触点配声音。** 链条开始活动、链绷紧和门合上各有一个时点。握瓶和松手分开，楼梯擦滑和扶栏分开。先听清对白，再听拟音是否贴合材质和空间。[声音源码](source/sound.py)
5. **回查导出的文件。** 先跑 node verify.cjs，再从最终 MP4 抽看换手、门链、扶栏和落桌的前后帧。完整解码并检查声轨。定稿后从同一套角色代码导出分层 SVG 和关节坐标。[验证脚本](source/verify.cjs) · [模型文件](models/)

## 注意事项

- 先看观众要从镜头里读到什么。中远景优先看身量、袖形和手的大小。特写把细节花在握住的位置、前后遮挡和松手时机上。
- 开门中景和特写用同一套门链规则。复查门框挂点、门扇挂点、松弛和绷直四处。递水时尤其检查静音播放是否仍能看懂由谁持瓶。
- 脚掌承重和腕部抓稳时要有固定落点。动作够不到目标时，改站位、重心或过渡时机，先检查臂长和腿长。镜头颤动跟随滑步，保留足够时间看清扶栏。
- 配音先按角色在当下的目的定重音、停顿和音量，再做距离和空间处理。这里的 90 秒交付采用既有合成对白做重混，验听时应把语气与混音分别判断。
- 单独改图可以编辑分层 SVG。要把修改带回动画，在角色源文件改相应的路径、尺寸或颜色，然后重新导出。导出模型时一起更新关节坐标与制作说明。[关节坐标](models/anchors.json) · [SVG 导出脚本](source/export-models.cjs)
