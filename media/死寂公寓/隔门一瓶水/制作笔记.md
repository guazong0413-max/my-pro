# 《死寂公寓 · 隔门一瓶水》制作笔记

长参考 81 分 47.585 秒。本次取 **1:03:32–1:05:02**，改写成 90 秒的二维试片。另一份 90 秒雨夜开场用于校准同一画风里的暗部、轮廓和镜头节奏。参考文件用于看片、取格、转写和声轨分析。发布的画面、道具、对白和声音均为本次重做。

## 从样片学到的做法

| 环节 | 参考里看到的细节 | 这次落到画面和声音 |
| --- | --- | --- |
| 构图 | 雨夜开场先给空间，再让窗帘、玻璃或门框遮住一部分。长参考约 63:34 用半开的门分开门里和楼道。 | 保持低饱和深蓝、低照度、平面色块和侧面轮廓。先用走廊全景定位置，再切屋内反打、门链、递水手部，最后让门底漏光接走注意力。 |
| 人物比例 | 全身侧面能看清成年人和孩子的身量差，也能看出头、肩、髋与前后脚。雨夜参考里摔落之后的镜头尤其依赖关节位置和支撑点。 | 手臂和腿各有固定的上下段长度。袖口连续接到手腕，肘部用转角折线和衣褶表达。站着时收直膝盖，前倾时由髋和躯干带动，脚跟、鞋底和踏面保持同一坐标。 |
| 交接动作 | 长参考约 63:53 递水，随后是停顿、目光和压低声音的承诺。 | 递瓶、接瓶、松指、收手各有姿态。26.8–34.4 秒用一条连续特写，瓶身位置驱动两只手。31.6 秒仍能看到两手同时握瓶，接稳后她才松开。 |
| 失衡、动作细节 | 雨夜跌落后的动作需要先交代接触和承重，再让重心移动。长参考约 64:11 转去楼梯。 | 在上楼处加入一记很短的踩滑。60.68 秒鞋底后移，膝髋下降。61.06 秒手碰扶栏，随后恢复步伐。扶栏用全身景别，镜头只随滑步轻微颤动。 |
| 配音 | 两份参考的对白通过短句、停顿、声源距离营造场景。以逐段转写、响度和波形核对节奏。 | 话说给门另一侧的人听，尾句收轻，叙述留一句给开场。小宇和小美的成品对白再放慢约 6%，按房间加短反射。对讲机用窄频和轻微饱和，大叔末尾只低声复述一句。 |
| 音效 | 雨夜开场用具体声响推进动作，长参考的门链、关门、脚步、对讲机帮助区分位置。 | 拟音按时间表逐项生成。鞋底、敲门、金属链、瓶壁、门锁和开麦各有独立声音，楼梯的反射比屋内长。对白旁留出停顿与低电平底噪。 |

## 复核

- 视频规格为 1920 × 1080、30 fps、90 秒。逐镜头抽帧核对侧脸、袖肘、腕指和道具的连接。
- 逐帧动作检查通过了 2,700 帧，覆盖 4,370 次臂段和 4,370 次腿段求解。递水有 31 帧的双手交接保持，扶栏有 12 帧稳定接触。
- 声轨复核采用台词转写、事件秒点、响度和峰值测量。口型从成品对白的逐帧音量提取。本版混音母带为 −21.2 LUFS，真峰值约 −2.2 dBTP。声音表演的主观听感由试片试听确认。
