# 《死寂公寓》二维镜头与动作

本目录下新增或重做人物动作时，沿用本系列的二维角色、布景与动作约定。先看参考片段，再把实际使用的机位和朝向写进分镜。

1. **先标机位。** 同一地点先定室内、走廊、门槛和楼梯的相对位置。每个镜头标相机在哪一边、人物从哪来、脚站哪里、脸朝哪里、眼睛看哪一点。屏幕左右根据机位换算。需要越过同一动作的视线轴时，用人物转向、门框前景或主观镜头交代换位。
2. **让人对着动作目标。** 背后看猫眼时画发髻、后脑和背部，眼位贴同一扇门的猫眼后再切室外主观。侧面拉门时先定角色在门内还是门外，脸朝实际把手，再摆抬手和发力。
3. **固定物件的锚点。** 同一扇门各镜头共用合页、门框、自由边、把手和开度。开合时手腕跟门扇上的实际握点，门扇到位后再松开把手收腕。走路前确定承重脚的落点、移动和转身时机。
4. **靠布景交代空间。** 楼梯用台阶、扶手和地面高差。环境标识只保留场景里合理、读者需要辨认的内容。字幕与布景文字分别检查。
5. **先验片再交付。** 静音连续看一遍。对照动作前、接触时、结束和剪切后的首帧，检查遮挡、门内外和视线是否接得上。用工程的逐帧检查复跑受影响镜头。新做朝向或接触的镜头，把相应的几何和动作约束加入本片检查。[门前的面粉验片](./门前的面粉/verify.cjs) · [这次朝向纠正的记录](./制作纠错记录.md)
