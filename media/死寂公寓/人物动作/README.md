# 《死寂公寓》人物动作

[播放人物动作样片](./死寂公寓-人物动作样片.mp4)。全片 36.5 秒，1920 × 1080，30 fps。四段均从第三人称观察人物，脚步、瓶底落桌和餐勺碰碗的声音跟随动作时间轴。

## 本轮需求

> 人物模型和声音是不是已经训练过了，那么好，现在开始训练动作，人物的姿态动作，比如走步，拿起放下手中的东西，吃饭，等等人物的行为是不是应该好好训练和设计啊，给我做一组模型图，以代码中的人物模型为基础，先做设计图，再做视频，记得要加上已经做好的表情

| 走路像蹲着滑，脚和身体各走各的 | 对照短样片 01:10.02–01:12.54 的侧面行走。素材里的摆脚贴近地面，上身起伏小，身体依次经过两只支撑脚。新版先定每次落脚和抬脚，用同一组点算胯的前移和承重高度。脚跟接地后滚到全掌，后脚再起来。固定侧面镜头看完整落脚，收步后才抬眼。 |

## 第二轮复查与修正

> “小孩那里还是穿模啊，大叔那里胳膊连接处，我都不想说，还有走路的时候别那么大声音”

- **小旭吃饭。** 放大旧成片发现碗沿画在袖子和右手之间，舀饭时腕部看起来被截断，手又盖在碗面上。本轮把碗移到桌面另一侧，左手放在腿边。右手的取勺、舀饭、退勺和放勺路线分别安排在碗外。舀饭用餐具特写，只有勺头到碗里，之后切回小旭送饭。放勺留在碗旁的桌面。
- **大叔的肩袖。** 原来袖根有一条平切边，胳膊一抬就从领口下面露出来。把袖根改成圆弧，接肩处用衣身的底色，袖子往外再稍加深。领口收成靠近颈部的一条短线，抬手和回手时一起检查肩侧轮廓。
- **脚步声。** 降低小宇和大叔的脚步声，减去一部分鞋底的高频和尾响。按相同落脚窗口测量，两个角色的脚步声均方根电平比上一版低约 11 dB。开篇脚步的峰值从约 −4.0 dBFS 降到约 −15.2 dBFS。

## 角色、动作和声音源码

- 复用已校准的二维头和表情，以及原人物的躯干、鞋和关节定位。袖形和裤腿跟着关节画成连续轮廓。四种角色的圆手大小分别设定。[人物模型](../隔门一瓶水/characters/) · [校准表情](../隔门一瓶水/characters/reference-style/) · [骨骼和绘制](./rig.cjs)
- 设计图和视频读取同一组姿势。改落脚、表情入点和道具接触时机时，先改动作时间轴，再重导设计图和视频。脚步、握瓶、碰碗、落勺和触耳麦的声音在同一段时间上核对。[动作时间轴](./motion.cjs) · [手和道具](./props.cjs) · [动作拟音](./foley.cjs)
- 动作试片保留同步拟音。已有开篇对白的配置单独存档。[开篇配音配置](../开篇九十秒/story.json) · [设计图渲染](./design.cjs) · [样片渲染](./reel.cjs)

## 验片

1. 先按正常速度看身体是否在落脚后移过支撑点，再停在脚跟落地、单脚承重、后脚收齐三处检查脚底和胯。
2. 放大检查取勺、舀饭和放勺。逐段看碗沿是否遮住该遮的勺头，右手和袖子是否保持在碗外，接着再看唇前、退勺和咀嚼。
3. 放大看大叔抬手和回手的中间姿势，检查领口和肩袖是否连贯，再看手心和耳罩的接触。
4. 跑逐帧脚本后，再从导出的 MP4 抽帧和完整解码。新版通过 1,095 帧检查，确认支撑脚接触点、握勺腕位和耳罩接触。小旭的 324 帧额外逐帧比较手、袖、头、碗和勺的绘制区域，碗和勺只在舀饭的时间内重叠。[逐帧检查脚本](./verify.cjs)

node verify.cjs
node design.cjs
node reel.cjs
