## 本轮需求

> 人物模型和声音是不是已经训练过了，那么好，现在开始训练动作，人物的姿态动作，比如走步，拿起放下手中的东西，吃饭，等等人物的行为是不是应该好好训练和设计啊，给我做一组模型图，以代码中的人物模型为基础，先做设计图，再做视频，记得要加上已经做好的表情

## 角色、动作和声音源码

- 复用已校准的二维头和表情，以及原人物的躯干、鞋和关节定位。袖形和裤腿跟着关节画成连续轮廓。四种角色的圆手大小分别设定。[人物模型](../隔门一瓶水/characters/) · [校准表情](../隔门一瓶水/characters/reference-style/) · [骨骼和绘制](./rig.cjs)
- 设计图和视频读取同一组姿势。改落脚、表情入点和道具接触时机时，先改动作时间轴，再重导设计图和视频。脚步、握瓶、碰碗、落勺和触耳麦的声音在同一段时间上核对。[动作时间轴](./motion.cjs) · [手和道具](./props.cjs) · [动作拟音](./foley.cjs)
- 动作试片保留同步拟音。已有开篇对白的配置单独存档。[开篇配音配置](../开篇九十秒/story.json) · [设计图渲染](./design.cjs) · [样片渲染](./reel.cjs)

## 验片

1. 先按正常速度看身体是否在落脚后移过支撑点，再停在脚跟落地、单脚承重、后脚收齐三处检查脚底和胯。
2. 看吃饭时圆手是否跟住勺柄、舀饭是否被前沿遮住、勺尖是否留在脸外。接着往后看退勺、咀嚼、落勺的顺序。
3. 看大叔抬手和回手的中间姿势，检查肘位置、袖形以及手心是否真正贴到耳罩外缘。
4. 跑逐帧脚本后，再从导出的 MP4 抽帧和完整解码。新版通过 1,095 帧检查，确认期间的支撑脚接触点、握勺腕位和耳罩接触。送勺到嘴边和退开的阶段也检查了勺子与头部绘制区域的重叠。[逐帧检查脚本](./verify.cjs)

## 重导出

在人物动作目录运行。复用开篇工程已锁定的 Canvas 依赖，视频编码需要支持 H.264 和 AAC 的 FFmpeg。

~~~sh
npm ci --prefix ../开篇九十秒
node verify.cjs
node design.cjs
node reel.cjs
~~~
