# 《死寂公寓》人物动作

[播放人物动作样片](./死寂公寓-人物动作样片.mp4)。全片 36.5 秒，1920 × 1080，30 fps。四段均从第三人称观察人物，脚步、瓶底落桌和餐勺碰碗的声音跟随动作时间轴。

## 本轮需求

> 人物模型和声音是不是已经训练过了，那么好，现在开始训练动作，人物的姿态动作，比如走步，拿起放下手中的东西，吃饭，等等人物的行为是不是应该好好训练和设计啊，给我做一组模型图，以代码中的人物模型为基础，先做设计图，再做视频，记得要加上已经做好的表情

## 角色与动作源

- 人物使用现有二维分层模型的头、衣服、袖口、手、腿和鞋。关节按原模型长度解算。脸部调用现有校准表情代码，保留短眉、点眼及嘴形，随动作切换视线、眨眼和口型。[人物模型](../隔门一瓶水/characters/) · [校准表情](../隔门一瓶水/characters/reference-style/)
- 修改动作幅度、表情入点或接触时机时，编辑时间轴。设计图和影片读取同一组姿势。走路时鞋跟和鞋尖围绕落地点滚动。抓瓶时腕位跟随瓶身，落桌后瓶子静止。吃饭时碗固定，勺尖先到唇边，口型配合张嘴、闭嘴和咀嚼。[动作时间轴](./motion.cjs) · [骨骼与原模型渲染](./rig.cjs) · [手形与道具](./props.cjs)
- 已存档的开篇对白由 `Qwen3-TTS-12Hz-1.7B-CustomVoice` 用 `Uncle_Fu` 和 `Serena` 两个预设音色生成。动作样片采用同步拟音，便于听辨脚跟落地、放瓶和放勺。[原配音配置](../开篇九十秒/story.json) · [动作拟音](./foley.cjs)
- 设计图和样片的渲染入口均可重新运行。[设计图渲染](./design.cjs) · [布景](./sets.cjs) · [样片渲染](./reel.cjs)

## 验证

按动画时间轴核对了 1,095 帧的关节长度、支撑脚、腕位和勺尖对唇位置。抽查了成片中的落脚、提瓶、进食和碰耳麦画面。MP4 已完整解码，H.264 画面和双声道 AAC 拟音均为 36.500 秒。

## 重导出

在 `人物动作` 目录运行。复用开篇工程已锁定的 Canvas 依赖，视频编码需要支持 H.264 和 AAC 的 FFmpeg。

```sh
npm ci --prefix ../开篇九十秒
node design.cjs
node reel.cjs
```
