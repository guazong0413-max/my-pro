# 《死寂公寓 · 第二声》

[播放 90 秒成片](./雨夜-第二声-Remotion.mp4) · [看分镜预览](./分镜预览.jpg)

这是《雨夜》的 Remotion 剪辑版。陈默在凌晨两点十七分被震醒，走到窗边看见对楼有人松开护栏。镜头最后停在自己家门底。沿用系列的二维角色、动作骨架及已制作的配音，本版重绘床头手机、雨中楼面、锁屏、玻璃雨滴和门底光影，并给护栏与花坛设计了新机位。

## 镜头与声音

| 成片时间 | 机位、动作和听点 |

| 00:08–00:27 | 锁屏亮起，播报贴近手机。赤脚声跟着落脚。陈默背对相机靠近窗缝，随后切到他的视角，从左边驶来的警车抬到对楼护栏。 |
| 00:27–00:37 | 保持同一侧机位。近景沿横杆移到右手，掌面压住上沿，袖口接到手腕。切回全景后人于 00:34.34 松手，镜头稍后跟落，00:35.72 碰到花坛。 |

近景试片里，双手与衣服两侧重合，姿态看起来像叉腰。现用相隔 82 个场景单位的握点，近景只跟右手，全景沿用同一组握点直到松手。侧卧时头部相对躯干抬起，撑地时用掌根接触土面。窗边背影的肩和颈共用倾身方向，反打保留已拨开的窗帘。

## 在 Remotion Studio 打开

在本目录执行以下命令。

```sh
npm ci
npm run studio
```

选择 `RainNight` 即可拖动时间线预览。导出使用 `npm run render`，成片写在本目录。分辨率为 1920 × 1080，每秒 30 帧，共 2700 帧。工程固定使用 Remotion 4.0.547。画面由 React/SVG 与浏览器原生 Canvas 2D 逐帧绘制。[Composition 入口](./src/index.jsx) · [Remotion 官方文档](https://www.remotion.dev/docs/idea)

[剪辑表](./edit.json)给出 22 个镜头的起始帧和声音入点。[分镜和机位](./src/scenes.cjs)复用系列角色骨架，[物件特写](./src/Inserts.jsx)控制雨滴、手机和门底光影。[声音与字幕时间线](./src/RainNight.jsx)分别装载旁白、对白、天气、动作和短音效。Composition 参数 `subtitles`、`narrationVolume`、`ambientVolume` 分别控制字幕开关、旁白和环境声电平。

## 声音与校验

工程附带八份可直接渲染的 FLAC。雨、风、手机马达、警笛和短吸气来自本系列自制音效，雨声随室内、窗边和楼外的听点变化。旁白沿用《雨夜》已生成的千问配音。声音编排见[分轨制作脚本](./prepare_sound.py)。如调整分轨处理，安装 Python 的 NumPy、SciPy 和 SoundFile 后运行 `python -B prepare_sound.py` 即可重新生成。

检查动作时先安装系列的本地 Canvas 依赖，再运行逐帧校验。

```sh
npm ci --prefix ../开篇九十秒
node verify.cjs
```

检查项包括握点间距、手掌在近景中的位置、下坠跟镜方向、脸与土面的距离、掌根承重、沙发遮挡位置和敲门入点。[逐帧校验](./verify.cjs)

片内中文字使用随工程附带的思源系列 Noto Sans SC 与 Noto Serif SC 字符子集。[无衬线字体授权](./public/fonts/film-sans-OFL.txt) · [衬线字体授权](./public/fonts/film-serif-OFL.txt)
