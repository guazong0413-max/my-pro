## 重做声音和机位

上一版的反馈是氛围带入不足。窗边、街道、房间之间的声音透视太浅，坠落和退回屋内的镜头需要跟上动作。这次以声音里的位置、距离和停顿来安排镜头。

原片分离出的旁白在 00:55.83–01:03.96 提供音频参考和对应文字。本地调用千问 Qwen3-TTS-12Hz-1.7B-Base 的音色复刻接口生成 20 条旁白，选取的参考也提供了说话节奏。陈默的低声对白和手机播报沿用各自的干声。雨、玻璃水点、马达、提示铃、脚步、落地、门外声和低频底音由独立的音效脚本生成，按画面事件入点混合。[台词、参考时码与事件](./story.json) · [本地音色复刻](./generate_clone_voice.py) · [声场与音效](./rain_audio.py) · [千问官方说明](https://github.com/QwenLM/Qwen3-TTS)

逐帧校验覆盖 2,700 帧和 14 个镜头段，核对窗缝视线、落体是否在画内、栏杆与花坛的接触、后退和落脚。配音单独检查台词和字幕时段。旁白和音效分轨都按 90 秒时间轴输出。[逐帧验片](./verify.cjs) · [系列机位与动作规范](../AGENTS.md)

## 在本目录导出

需要 Node.js、Python 的 NumPy 与 SciPy，以及带 H.264、AAC 和 rubberband 的 FFmpeg。干声已归档，可以直接混音和渲染。

~~~sh
npm ci --prefix ../开篇九十秒
python mix_rain.py --narration-stem 旁白分轨.wav --effects-stem 音效分轨.wav
node verify.cjs
node film.cjs
~~~

重配旁白时，在已安装千问推理依赖的环境中，将原片旁白 WAV 的本地路径传给 `--reference`。脚本按剧本时码从 90 秒 WAV 中读取参考段。需要重录手机播报或陈默时，分别选 `warning`、`what` 和 `no`。

~~~sh
python generate_clone_voice.py --reference "本地的原片旁白.wav" --only time wake
python ../门前的面粉/generate_voice.py --plan story.json --voice-dir voice --only warning what no
~~~
