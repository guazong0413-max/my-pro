# 《死寂公寓》雨夜短片

[播放 90 秒成片](./死寂公寓-雨夜短片.mp4) · [查看分镜预览](./分镜预览.jpg) · [下载同步混音](./同步混音.wav)

按雨夜参考短片的 00:00–01:30 制作。陈默在凌晨 02:17 被手机震醒，摸黑走到窗前，从窗帘缝里看见对楼的人松开栏杆。参考片用于核对原文、机位、动作和声音。人物、窗外街景、手机画面、配音及拟音均在工程中重新制作。

## 配音与验片

原片字幕和实际读音用来校对 23 条配音。千问采用 Qwen3-TTS-12Hz-1.7B-CustomVoice。旁白按普通话的中低声区逐句给停顿和收尾，陈默两句对白压低声量，手机播报带轻微的扬声器频带。较长的合成气口按镜头入点缩短。雨声分室内、窗边和室外三层，赤脚落步比对白轻。[台词、节奏提示和拟音入点](./story.json) · [千问干声](./voice/) · [混音代码](./mix_rain.py)

验片调整了花坛中撑起时两脚落地的顺序、窗帘松手的接触位置、脚部特写的裁切和侧脸与肩颈的衔接。画面统一按项目的二维色块与圆手做法绘制。逐帧校验覆盖 2,700 帧、14 个镜头段、29 条字幕，并核对栏杆、花坛、手腕、脚底及窗内外方向。音视频均为 90.000 秒。[逐帧验片](./verify.cjs) · [系列机位与动作规范](../AGENTS.md)

## 在本目录导出

需要 Node.js、Python 的 NumPy 与 SciPy，以及带 H.264、AAC 和 rubberband 的 FFmpeg。现有干声可直接混音。

~~~sh
npm ci --prefix ../开篇九十秒
python mix_rain.py
node verify.cjs
node film.cjs
~~~

重新合成配音时请在已安装千问推理依赖的环境中运行。

~~~sh
python ../门前的面粉/generate_voice.py --plan story.json --voice-dir voice --only what no
python mix_rain.py
node verify.cjs
node film.cjs
~~~
